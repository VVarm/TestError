# TestError

Учебный Python-проект с JSON-конфигурацией и двумя намеренными ошибками.
Зависимости: только стандартная библиотека Python 3.

## Файлы

- `main.py` — точка входа.
- `config_loader.py` — чтение `config.json` из папки проекта.
- `calculator.py` — вычисление выражения.
- `config.json` — пример безвредного арифметического выражения.

## Намеренные ошибки

1. Синтаксис: после `def calculate(expression)` пропущено двоеточие.
   Поэтому `python main.py` завершится с `SyntaxError`.
2. Безопасность: `eval(expression)` исполняет Python-код из конфигурации.
   Если посторонний изменит конфигурацию, он сможет выполнить произвольный код
   с правами запустившего программу пользователя. Пример оставлен уязвимым
   специально для практики; не используйте его с недоверенной конфигурацией.

Для исправления второй ошибки замените `eval` ограниченным разбором
арифметических выражений с явно разрешёнными операциями.
